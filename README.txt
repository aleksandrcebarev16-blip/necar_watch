NECAR WATCH — минимальный сайт совместного просмотра

Запуск на компьютере:
1. Установите Python 3.11 или новее.
2. В папке проекта выполните:
   pip install -r requirements.txt
   uvicorn main:app --host 0.0.0.0 --port 8000
3. Откройте http://127.0.0.1:8000

Публикация:
Загрузите файлы проекта в хостинг Python, поддерживающий WebSocket (например, Replit).
Запускная команда: uvicorn main:app --host 0.0.0.0 --port 8000
После запуска хостинг выдаст публичный HTTPS-адрес. Отправьте партнёру URL комнаты.

Возможности:
- отдельная комната по ссылке;
- лимит 2 участника;
- чат;
- YouTube-плеер и синхронизация управления;
- прямые MP4/WebM/Ogg-ссылки с синхронизацией;
- попытка встроить другие сайты, если они разрешают iframe.

Ограничения:
Не существует универсального способа встроить и синхронизировать любой сторонний сайт.
Некоторые сайты запрещают iframe, требуют авторизацию или блокируют внешнее управление плеером.
Для таких сайтов используйте официальный способ просмотра; синхронизация может быть недоступна.
Публичный хостинг нужен для работы с партнёром через интернет.
